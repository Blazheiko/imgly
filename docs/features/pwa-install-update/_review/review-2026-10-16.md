- **Boundaries:** infra imports only `@/core`. The feature imports only `@/core`, `@/features/editor`, `@/infra/platform` and `@/shared`. There are no feature-to-feature imports, and `test-hooks.ts` imports through the feature's `index.ts`.

- **Tests:** no `.only` and no new `.skip`. Moving `mark` behind `onControllerChange` follows the intended §6.1 change. The new tests cover failure paths for real.
- **Production hygiene:** test hooks load only behind `VITE_E2E_HOOKS`.
- **Runtime:** the switch timeout writes no marker, and a late `controllerchange` raises only `updated-elsewhere`. Cancel and Esc unlock. A registration error resolves the start check. A second `beforeinstallprompt` after a dismissal shows the action again, and `appinstalled` clears it. If another window triggers a `controllerchange` while a switch is pending, this window reloads into the newest version.
