## Confirmed clean

- **Hold and leave:** every path that sets `reloadHeld` releases it (Cancel and Esc, the 10 s give-up, the reload itself). `onControllerChange` clears `switchRequested` and its timer before it marks, so there is no double reload and no race with the timer. Outside an update the Editor behaves as before.
- **Toast:** focusing the action on click changes no `role`, `aria-live`, order or keying. The Gallery `damaged` → Delete toast now behaves the same in every browser. `design-system.md` is updated.
- **Re-raised notice:** `raise` returns early only for the same wording. A different wording still replaces the notice, and a dismissed notice comes back for a newer waiting worker.
- **Tests:** no `.only` and no new `.skip`. The new App test with "another button" focused fails without the Toast fix, and the click tests check real refusals.
- **Boundaries:** no new imports between features. `gallerySaving` is exposed only through `test-hooks.ts` behind `VITE_E2E_HOOKS`, and `e2e/test-hooks.d.ts` matches. No new CSS, ids or error codes.
