# Domain Context — adjust

## Glossary

- Auto adjust — a one-click action in the "Adjust" tool that sets the Draft's brightness, contrast, temperature and tint from the pixels inside the Work's Crop, always the same values for the same Work and Geometry; the Editor sees them on the sliders, can change them, and they reach the Work only on Apply. NOT a preset or a filter with hidden settings: it only moves the visible sliders, and leaves saturation, grayscale and sepia as they are.
- Compare — holding a control in the "Adjust" tool to see the Preview with the Work's Geometry but no Adjustments at all, and returning to the Draft when it is released; it never changes the Work or the Draft. NOT Cancel, which throws the Draft away, and NOT Reset, which sets the Draft to neutral values.
- Draft — the Adjustments being changed in the open "Adjust" tool; they reach the Work only on Apply and are thrown away by Cancel, Escape or replacing the Work. NOT Unsaved edits: changes in the Draft never count as Unsaved edits until they are applied. NOT the crop-rotate Draft, which holds a Geometry.
