## Checked and holding

- **US/AC trace:** every US-01–US-08 has at least one AC, a sad §6 flow (F1–F7, Critical flows 1–3) and a ux-flows flow. All 21 ACs are claimed by a task, and every task is done in `tracker.md`. Every screens.md state on SCR-01–SCR-07 is built, including display-lost, the "Before" pill, the hint line, and focus moving to brightness and back to the action. Exact values, ranges, step, neutral marks, the "%" unit, the copy strings, the A, C and `\` keys, and Enter/Escape handling all match the AC text.
- **ADR-0002/0003:** the GLSL block (`src/render/shaders.ts:46-69`) matches `formula.ts` and `uniforms.ts` step for step: the order, a clamp after each step, the neutral skip guards and the column-major sepia matrix. It unpremultiplies, keeps alpha, and keeps alpha 0 transparent. The `u_adjust` bypass gives exact neutral output, and the anchor values check out.
- **Export:** the single-pass path is byte-identical to before for full size or neutral values. The two-pass path (`worker-handler.ts:228-266`) adjusts at full size with the same filtering, then reduces with the JPEG flatten in the second pass only. The window fallback passes the whole request.
- **ADR-0001 / AC-11:** the snapshot carries only applied Adjustments, and `applyAdjustments` compares field by field. A replaced Work starts from NEUTRAL.
- **ADR-0004:** `sampleCrop` uses `work.geometry` with NEAREST, neutral values and no flatten, and frees its resources. Fully transparent, uniform-opaque and 1×1 samples return `nothing` (apart from the R2 soft-alpha case).
- **Conventions and boundaries:** the only cross-feature import is `@/features/editor` (plus `type ToolId` in export). Styling comes from tokens only. Every keydown, keyup and blur listener is removed on unmount. Compare ends on pointerup, pointercancel, pointerleave and blur. Crop-rotate and export tests only gained cases; no assertions were loosened. There is no `.only`, and no fixed sleeps in `e2e/adjust`. Test hooks are absent from the production bundle.
