## Checked and holding

- **US/AC trace:** every US-01–US-09 has at least one AC, a sad §6 flow (F1–F8) and a ux-flows flow. Every AC reaches a task, code and a test, except for the gaps listed above. Every screens.md state for SCR-01–SCR-06 is built by a component.
- **Cross-feature overrides:** export AC-17 is narrowed correctly. Ctrl/Cmd+S shows the hint while a tool is open and is unchanged otherwise. The status bar shows "w × h px, from W × H px", so open-and-view AC-05 and AC-06 hold. Export AC-09 and open-and-view AC-15 are re-verified with a real Geometry (editor store tests, `tool.spec.ts` AC-17).
- **ADR-0001:** one Crop-to-Original transform in core (`cropToOriginalUv`, `turnedImageToOriginalUv`, `turnedBounds`, `cropRectOnScreen`). The Preview in both modes, the export worker, the alpha check, the test-hook render and the overlay all use it.
- **Transform maths:** all 16 Rotation × Flip matrices are correct and compose with a Straighten angle. Pixel centres land on texel centres. Preview and Export share the NEAREST/LINEAR rule.
- **ADR-0002:** one shader pass.
- **AC-06 (no empty corner):** probed at ±45° and other angles on 9 sizes from 4096×3072 down to 1×7. The worst corner pixel centre stays 0.87 px inside, so no transparent sliver is possible.
- **ADR-0003:** the Draft lives in the crop-rotate store, and the editor store owns only the tool slot.
- **Editor store:** Unsaved edits change only when the applied Geometry differs (AC-13). Cancel and replace behave correctly. Export and the panel are refused while a tool is open (AC-16).
- **Validation (AC-07, AC-10):** `parseDecimal`, `parseAngle` and `parseCropSize` handle Infinity, `-0`, exponents and empty input as specified. Export sizes count from `workSize`.
- **Conventions:** core stays pure, features import each other only through `index.ts`, and no new error codes were added.
- **Design system:** scoped CSS uses only tokens. The BaseButton `pressed`, NumberField `decimal`/`decimals`/Escape and SliderField `step`/`decimals`/`marks` extensions are registered in `docs/design-system.md`.
- **Lifecycle:** pointer capture, cancel and lost-capture are handled. Window listeners and the fine-grid timer are cleaned up on unmount. Focus goes to the frame on open and back to the action on close.
- **Test hooks and e2e:** the hooks load only behind `VITE_E2E_HOOKS`. The e2e specs use no fixed sleeps.
