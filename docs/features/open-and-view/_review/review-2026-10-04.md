# Review — open-and-view

## Scope

- Diff `90f60ed..d6e1bc1` on `feature/open-and-view`: 21 commits (T1–T20, plus the T20 perf measurement fix). 158 files changed, about 7.9k insertions.
- Four independent, clean-context `sdd:reviewer` passes (opus), one per dimension:
  1. Stage-1 trace for AC-01–AC-11b.
  2. Stage-1 trace for AC-12–AC-19b, plus ADR fidelity.
  3. Stage-2 quality and module boundaries.
  4. Security, which spec §6.1 marks as required.
- The author's session checked each stage-1 finding and the main stage-2 findings against the code before resolving them.
- Gate when the review started: `pnpm lint`, `pnpm typecheck` and `pnpm test` all pass (356/356). Three-engine e2e: 199 passed, 8 skipped by design.

## Clean

- **Use-case floor:** every user story US-01–US-08 has at least one §5 AC and at least one `sad.md` §6 flow.
- **ADR fidelity:** feature ADRs 0001–0005 and repo ADRs 0001, 0002 and 0004 are honoured. Decoding happens only in the worker, headers are parsed in core before decode, there is one WebGL2 canvas, every Original is converted to sRGB, and View changes never touch the revision.
- **Module boundaries:** respected. `src/core` has no Vue, Pinia or DOM imports; `shared` never imports features, infra or render; cross-module imports go through `index.ts`. The infra→core widening is guarded by `import-rules.test.ts`.
- **Conventions:** IDs come from `newId()`, new AppError codes are in the typed union, and all 5 new primitives are registered in `docs/design-system.md`. Every `screens.md` state is built.
- **Security, clean areas:**
  - The parser has bounds checks and capped loops, and never allocates in proportion to a declared size.
  - SVG is refused by content and never rendered.
  - There is no `v-html` or `innerHTML`, and file names never reach the DOM.
  - The only object URL is revoked.
  - Metadata is not carried into the Original.
  - The service worker precaches app assets only.
  - The test hooks are gated on `VITE_E2E_HOOKS` and absent from `dist/`.
- **AC traces that are OK:** AC-01, AC-02, AC-04, AC-05, AC-06, AC-07, AC-09 (apart from the GIF gap below), AC-14, AC-15, AC-16, AC-17, AC-18, AC-19.
