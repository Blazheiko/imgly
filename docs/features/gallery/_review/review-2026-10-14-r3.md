## Checked and holding (this round)

- `onStored` runs only after the transaction has committed (`autosave.ts:140-145`). A failed save, a failure in preparation or a throw never clears a mark. Both replace paths go through `replaceRestored`. A superseded restore clears nothing.
- The R2-7 harness change made no test vacuous. The two existing `commitFail` tests are first saves and still abort at the marker `put`. No other test uses the fault.
- The open Work winning over a damaged stored record is consistent with AC-07. The next successful save replaces the record whole. The record shows Damaged again once another Work replaces this one, so nothing the spec protects is hidden for good.
- The `defaultPrevented` guard blocks no legitimate tool key. Nothing earlier calls `preventDefault` on Esc or Enter in crop-rotate. Adjust and Draw already had this guard.
- `galleryModal` also covers the delete dialogs on SCR-01 and inside the overlay, which is correct for a modal.
- Boundaries and tokens: `gallery` reaches the editor only through `@/features/editor`. No feature imports another, and no new styling was added.
